# Apexplain has no Python TTS dependencies.
# Install Node packages with: npm install
#
# Local-first after setup — make/ui do not call the network.
#
# Models (downloaded once, then used offline):
#   English  — npm run setup:kokoro      (~88 MB → ~/.cache/apexplain)
#   zh-HK    — npm run setup:vocello     (~2.23 GB Vocello pro_design_speed
#              → ~/Library/Application Support/QwenVoice/models/)
#              Requires Vocello Mac CLI first:
#              https://github.com/PowerBeef/Vocello/releases
#
# Network:
#   APEXPLAIN_ALLOW_HF=1   — allow Hugging Face during Kokoro load (setup sets this)
#   Autogenerate may call Wikipedia for topic facts (disable with APEXPLAIN_OFFLINE=1)
#
